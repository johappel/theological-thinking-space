# Theological Thinking Space – Prototype 02

Kleiner statischer UX-Prototyp für den neu fokussierten theologischen Denkraum.

## Ziel

Nicht zuerst einen Gottesdienst erzeugen, sondern prüfen, ob ein digitaler Raum eine erkennbare theologische Denkbewegung der Vorbereitenden unterstützen kann.

Ablauf:

1. Ausgangspunkt einbringen
2. wenige Perspektiven gezielt einladen
3. Resonanzen, Irritationen, Spannungen, Fragen und vorläufige Zeugnisse festhalten
4. bewusst `Zur Schwelle` wechseln
5. dort zwischen eigener Erfahrung / Zeugnis und offener Gestaltung für andere unterscheiden

## Start

Einfach `index.html` im Browser öffnen.

Es gibt noch:

- kein Backend
- keine echte KI-Anbindung
- kein Research-System
- kein Langzeitgedächtnis über `localStorage` hinaus
- keinen Gottesdienst-Generator

Die Perspektiven sind absichtlich nur simulierte Fragen. Damit soll zuerst die UX-Hypothese getestet werden.

## Nächster Test

Nach 15–20 Minuten Nutzung sollte geprüft werden:

- Hat sich die Ausgangsfrage verändert?
- Ist eine tatsächliche Denkbewegung sichtbar?
- Haben die Perspektiven den Prozess vertieft oder nur Text produziert?
- Fühlt sich `Zur Schwelle` wie ein sinnvoller Übergang an?
- Verhindert die Schwelle, dass eigene Erfahrung einfach auf die Gemeinde übertragen wird?
